1) ارفع المجلد كامل على GitHub واربطه بـ Netlify (index.html + netlify.toml + netlify/functions/tripo.js).
2) Netlify > Site configuration > Environment variables:
   TRIPO_API_KEY = مفتاح Tripo (platform.tripo3d.ai)
   ACCESS_CODE   = (اختياري) كلمة سر حتى ما أحد يصرف رصيدك
3) اعمل Deploy مرة ثانية بعد إضافة المتغيرات.
